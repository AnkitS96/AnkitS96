## Hi, I'm Kit 👋

I'm a performance marketer in Berlin. For almost four years I ran paid campaigns on **Meta** for **80+ brands in 30+ markets**, with budgets of €5k to €25k a month per account. I like the unglamorous part that decides whether ads work: **tracking that is correct**, tests that change one thing at a time, and reports that are ready before anyone asks.

Lately I've been teaching software to do the boring parts of my own job.

- 📉 Cut weekly reporting from **6 to 8 hours to under 90 minutes** with an n8n workflow and an LLM.
- 🔧 Set up **Meta Pixel, Conversions API and Google Tag Manager on 100+ shops a month**.
- 🧪 Single A/B tests lifted leads or signups by **20% to 50%**.
- 🇬🇧 English (C2) · 🇩🇪 German (B1) · 🇮🇳 Hindi (native)

## 🚀 Featured project: Spend Watch

> A paid media monitor that watches daily ad spend, flags **spend spikes, creative fatigue and tracking gaps**, and drafts the weekly brief. **Every action waits for a human to approve it.**

Built with Claude Code as a single-file app.
